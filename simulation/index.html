HOW TO USE

From iSAMS to your wallpaper

1ImportSave the iSAMS PDF and upload it here
2AdjustCorrect individual cells or fill several at once
3ExportChoose a device and download the wallpaper
1

IMPORT THE SOURCE

Save your timetable from iSAMS

Open Timetable

Tap Timetable in the portal navigation.

Open My Timetable

Wait until the complete Monday–Friday grid appears.

Open the share menu

Tap Share, then choose Save to Files.

Import the PDF

Return here, open Import, and choose the saved file.

2

ADJUST YOUR TIMETABLE

Correct the timetable

ONE CELL

Use Timetable

  1. Open Timetable.
  2. Tap the cell you want to change.
  3. Edit Course, Teacher, Room or Note in Cell Editor.
  4. Your change is saved automatically.
SEVERAL CELLS

Use Batch entry

  1. Open Batch entry.
  2. Select the target cells.
  3. Choose a detected block and select Apply block.
  4. For a new activity, add a Personal lesson first.
3

CREATE THE WALLPAPER

Export the timetable

Choose Device

Default, iPad Pro or Phone.

Choose Format

Default is fixed. Device wallpapers can use Reg–P12 or P13/P14.

Check Preview

Check the timetable.

Download PNG

Save the image.

Before downloading: check the Timetable page first. The wallpaper uses the timetable currently saved in this browser.
