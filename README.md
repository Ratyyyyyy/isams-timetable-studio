# Timetable Studio

A browser-only timetable editor and wallpaper generator with an iSAMS-inspired staff-portal interface.

## Features

- Click any timetable cell to edit course, teacher, room and notes.
- Edit period labels and times, including P13 and P14.
- Duplicate a lesson into the next period for double lessons.
- Local browser autosave; no account or server database.
- JSON import/export for backups.
- PNG export for:
  - iPad full-day timetable
  - iPad campus timetable
  - Phone full-day timetable
  - Phone campus timetable

## Privacy

All timetable edits stay in the current browser's `localStorage`. The site does not connect to the school portal and does not send timetable data to a server.

## Run locally

Open `index.html`, or serve this folder with any static web server.

This is a personal planning tool and is not an official iSAMS or school service.
